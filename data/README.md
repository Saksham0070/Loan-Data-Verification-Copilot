# Demo data package

| File | Purpose |
| --- | --- |
| `sample_loans.csv` | Messy primary loan tape for the end-to-end demo |
| `sample_loans_clean.csv` | Valid baseline input |
| `sample_loans_invalid.csv` | Focused negative test input |
| `servicer_update.csv` | Secondary source containing potential conflicts |
| `document_manifest.csv` | Document-status source evidence |
| `validation_rules.json` | Editable validation rule configuration |
| `users.json` | Seeded role definitions |
| `expected_exception_sample.csv` | Expected-exception orientation sample |

All files are synthetic and safe for local demonstrations.
